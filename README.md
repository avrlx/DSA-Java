# Data Structures and Algorithms (DSA) in Java 🚀


Welcome to my repository dedicated to mastering Data Structures and Algorithms using Java! This repository serves as a personal log of my problem-solving journey, algorithmic implementations, and conceptual notes.

## 📁 Repository Structure

The project is organized by topic for easy navigation:
* `Arrays/` - Array manipulation, sliding window, two-pointer problems.
* `LinkedList/` - Singly, doubly, and circular linked lists.
* `Trees/` - Binary Trees, Binary Search Trees (BST), and traversals.
* `Graphs/` - BFS, DFS, and shortest path algorithms.
* `Algorithms/` - Sorting, searching, and dynamic programming patterns.

## 🛠️ Prerequisites & Setup

To run the code in this repository locally, ensure you have the following installed:
* **Java Development Kit (JDK)** (Version 17 or higher recommended)
* An IDE like **IntelliJ IDEA**, **Eclipse**, or **VS Code**

### Running a File Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/avrlx/DSA-Java.git
   ```
2. Navigate to the specific topic folder:
   ```bash
   cd Arrays
   ```
3. Compile and run the Java file:
   ```bash
   javac CodeFileName.java
   java CodeFileName
   ```
